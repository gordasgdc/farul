Farul 0.2.0 — first public release. Free, MIT license.

**EN** — Lightweight system monitor for the macOS menu bar: CPU, memory, network, disks, battery and top processes. Sampling pauses while your Mac sleeps, memory pressure follows the system, diagnostics can be exported (redacted), full uninstall from Settings, verified updates with automatic rollback. Romanian, English, Spanish. macOS 13+, Apple Silicon. Install: download `Farul-0.2.0.pkg`, double-click.

**RO** — Monitor de sistem ușor pentru bara de meniu macOS. Eșantionarea se oprește cât doarme Mac-ul, presiunea de memorie urmează sistemul, diagnostic exportabil, dezinstalare din Setări, actualizări verificate cu revenire automată. Instalare: descarcă `Farul-0.2.0.pkg`, dublu-clic.

**ES** — Monitor de sistema ligero para la barra de menús de macOS. El muestreo se detiene mientras el Mac duerme, diagnóstico exportable, desinstalación desde Ajustes, actualizaciones verificadas con reversión automática. Instalación: descarga `Farul-0.2.0.pkg` y haz doble clic.
